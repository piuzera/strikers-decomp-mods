# Demo media

User-provided captures of the completed proof of concept:

- `captain-select.png`: Screenshot 1, selectable Palmeiras captain crest.
- `sidekick-select.png`: Screenshot 2, selectable Human sidekick.
- `match-ready.png`: Screenshot 3, pre-match matchup/crest presentation.
- `gameplay.png`: Screenshot 4, expanded-team gameplay on the enlarged Palace.
- [Full recording on Streamable](https://streamable.com/v007kw): Recording 1,
  the ~86-second title-screen-to-match demonstration, hosted externally.
- `demo-preview.gif`: 8-second gameplay excerpt from that recording, 360 pixels
  wide at 8 fps, used for a reliable inline animated preview.

GitHub READMEs do not support Streamable iframe embeds. The README uses an inline
animated preview linked to the full hosted recording. The complete video is no
longer stored in the repository's current tree.

Gameplay contains Nintendo/Next Level Games content and club marks. These
captures are not relicensed as an MIT or CC0 asset collection.
